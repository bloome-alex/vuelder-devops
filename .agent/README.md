# Configuracion Principal De Agentes

Esta carpeta define las reglas, fundamentos y recursos que deben seguir los agentes al trabajar en este proyecto DevOps.

## Objetivo

Garantizar que cualquier cambio mantenga una arquitectura modular, escalable, segura, testeada, documentada y orientada a clases y objetos.

## Archivos

- `instructions.md`: reglas globales de desarrollo para agentes.
- `architecture.md`: fundamentos de arquitectura, capas y estructura del proyecto.
- `coding-standards.md`: convenciones de codigo, TypeScript, Express, Docker y seguridad.
- `workflow.md`: flujo obligatorio para implementar cambios.
- `skills/`: guias operativas para tareas repetibles.
- `templates/`: plantillas base para modulos, documentacion y tests.
- `scripts/`: scripts auxiliares propios de agentes cuando una tarea grande lo requiera.

## Regla Principal

Antes de programar, un agente debe revisar esta carpeta y aplicar sus convenciones. Si un desarrollo introduce una nueva practica repetible, debe documentarse como skill o automatizarse con un script.
