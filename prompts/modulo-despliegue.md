# Modulo de Despliegue

## Objetivos
- Visualizar un listado con todos los servicios desplegados en docker.
- Campos a visualizar por cada servicio. Nombre del servicio, imagen:tag, puertos, fecha de creación, fecha de actualización.
- Cada servicio debe poder abrirse como acordeon mostrando las tareas ejecutadas con las siguientes propiedades: Estado, Fecha de creación, Fecha de actualización, Nodo, Tarea, Acciones.
- Cada tarea debe poder inspeccionarse para ver más detalles.

## Acciones
- Botón para actualizar listado
- Reiniciar servicio
- Eliminar servicio
- Inspeccionar servicio
- Inspeccionar tarea
- Paginación al listado
